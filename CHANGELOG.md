# Changelog

## v1.2.0 — Аппаратный оверлей, оптимизация и новое меню

### Оптимизация и производительность
- **Аппаратный оверлей (`Direct2D 1.1 + DirectWrite + DirectComposition`):** полностью заменён медленный CPU GDI `UpdateLayeredWindow` (8.3 МБ DIB на кадр). Теперь рендер идёт на GPU с `DXGI_SWAP_EFFECT_FLIP_SEQUENTIAL` и `Present(0, 0)` без искусственного потолка в ~64 FPS.
- **Ускорение инференса (`YoloDetector`):**
  - Предвыделены и переиспользуются `Ort::MemoryInfo`, входной/выходной `Ort::Value` и `Ort::RunOptions` (0 аллокаций на кадр; исправлена проблема с однократным `IoBinding` в DirectML, из-за которой модель работала по нулевому кадру).
  - Добавлен прямой SSSE3-препроцессинг `BGRA -> RGB NCHW float / 255` — захват экрана переключён в нативный `BGRA` без лишней промежуточной конвертации в `BGR`.
  - Отложенное чтение координат боксов при постпроцессинге (только для anchors выше порога `Conf`).
- **Многопоточность и тайминг:**
  - `FrameChannel` переведён на `O(1)` `swap` буферов вместо `memcpy` под мьютексом.
  - Трекинг (`ApplyDetections`) и наведение (`MoveMouse`) перенесены в поток инференса — наведение срабатывает сразу по готовности кадра YOLO без ожидания UI-цикла.
  - Независимый расчёт телеметрии: `CAP fps`, `DET fps`, среднее время инференса (`ms`) и `UI fps`.
  - Точный high-resolution `nextFrame` пейсер (`CreateWaitableTimerExW`) с настраиваемым лимитом UI FPS (`60..300`, `Без лимита`).

### Новое меню (стиль Skeet / GameSense)
- **Открытие поверх игры без сворачивания:** окно меню переведено на `WS_EX_NOACTIVATE` + `SW_SHOWNOACTIVATE` + `MA_NOACTIVATE` (с опциональным переключателем `Перехват фокуса` для игр, жёстко блокирующих курсор). Открытие/скрытие работает по `N` и `Insert`.
- **Интерфейс:** двойные резкие рамки, верхняя радужная градиент-полоса, узкий левый сайдбар с иконками и вырезом активной вкладки, двухколоночная сетка групбоксов, градиентные лаймовые слайдеры, квадратные `9×9` чекбоксы и встроенные `[KEY]`-теги.
- **Новые настройки и пресеты:**
  - Вынесены в меню `Включить аим`, `Сила доводки`, `Макс. шаг мыши`, `Мёртвая зона`, `Порог NMS (IoU)`, `Лимит UI FPS`.
  - Вкладка `Настройки` с живым статусом, профилями `Legit` / `Fast` / `Rage` и кнопками `Load`, `Save`, `Reset`, `Unload`.
  - Автосохранение `f6.cfg` при закрытии меню и выходе, возможность отключать доп. клавишу аима по ПКМ.

### Исправления
- Исправлен click-through проброс кликов мыши через новый DirectComposition-оверлей (возвращён `WS_EX_LAYERED` в связке с `WS_EX_NOREDIRECTIONBITMAP | WS_EX_TRANSPARENT`).
- Исправлена ошибка с кэшированием входного буфера в DirectML, из-за которой детектор переставал видеть цели (`maxConf = 0.001`).
- Убрана жёсткая запись `debug.log` в корень проекта.
